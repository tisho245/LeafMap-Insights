--- ИНСТРУКЦИИ ---
--- Стъпка 1: База данни ---

Вариант A – SQL Server вече работи на localhost:1433 с парола sa (напр. SuperAdmin2026).
Вариант B – пусни само SQL в Docker:
   docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=SuperAdmin2026" -p 1433:1433 -d mcr.microsoft.com/mssql/server:2022-latest
   Изчакай 20–30 s преди да стартираш API-тата.

В appsettings.json на двата API проекта connection string-ът трябва да съвпада, напр.:
   Server=localhost,1433;Database=LeafMapInsights;User Id=sa;Password=SuperAdmin2026;TrustServerCertificate=True;

--- Стъпка 2: Стартиране на Auth API и Data API ---

Терминал 1 – Auth API (порт 5203):
   cd LeafMapInsightsAuthAPI\LeafMapInsightsAuthAPI
   dotnet run --urls "http://0.0.0.0:5203"

Терминал 2 – Data API (порт 5202):
   cd ASPLeadMapInsightsAPI\ASPLeadMapInsightsAPI
   dotnet run --urls "http://0.0.0.0:5202"


Проверка:
- http://localhost:5203/swagger  → Auth API
- http://localhost:5202/swagger  → Data API (trees, divisions, families, genera, species)

--- Стъпка 3: Уеб клиент (Node) ---

1. В LeafMapInsightsNodeClient\LeafMapInsightsNodeClient създай .env (или копирай .env.example):
   API_BASE_URL=http://localhost:5202
   AUTH_API_BASE_URL=http://localhost:5203
   PORT=3000

   Ако тестваш от друг компютър в мрежата, вместо localhost използвай IP на машината с API-тата.

2. Стартирай Node сървъра:
   cd LeafMapInsightsNodeClient\LeafMapInsightsNodeClient
   npm install
   node server.js

3. Отвори http://localhost:3000 – трябва да видиш уеб приложението. Регистрирай се или влез, после тествай списък дървета, карта, таксономия, добавяне на дърво.


--- Стъпка 4: Мобилно приложение (MAUI) ---

1. Отвори MAUILeafMapInsights\MAUILeafMapInsights.sln.

2. Настрой API адресите в Services\ApiSettings.cs:
   - На емулатор Android: BaseUrl = "http://10.0.2.2:5202", AuthApiBaseUrl = "http://10.0.2.2:5203"
   - На реално устройство в същата Wi‑Fi: използвай IP на компютъра, напр. http://192.168.1.5:5202 и :5203
   - На Windows (локално): BaseUrl = "http://localhost:5202", AuthApiBaseUrl = "http://localhost:5203"

3. Увери се че Auth API и Data API работят (стъпка 2).

4. Стартирай приложението: избери Android Emulator (или Windows) и Run (F5). Влез с регистриран акаунт или admin; тествай Дървета, Карта, Таксономия, Добави дърво.
