# 2.1.4. Избор на технологии

Избират се технологиите за всеки компонент. За **Backend:** ASP.NET Core Web API, Entity Framework Core, SQL Server, ASP.NET Core Identity, JWT Bearer. За **Web:** Node.js, Express (сървър за статични файлове и endpoint за конфигурация), HTML/JavaScript в браузъра, заявки директно към API (fetch/axios), JWT в localStorage; конфигурацията на API адресите се подава чрез GET /api-config. За **Mobile:** .NET MAUI. Критериите са съвместимост, поддръжка, възможност за екип с .NET опит и възможност за общ API договор.
